YouTube RAG Q&A System is a retrieval-augmented question answering application built over YouTube video transcripts. The system ingests long transcripts, splits them into overlapping chunks, generates embeddings using SentenceTransformers, and retrieves the most relevant content using cosine similarity. Answers are generated strictly from retrieved context, and the system returns a clear fallback when the information is not present, preventing hallucinations.

This project demonstrates a real-world RAG pipeline with retrieval-first design, semantic search, and explainable answers with source attribution. It is implemented as a full-stack application using FastAPI for the backend and React (Vite) for the frontend, following a clean and production-ready structure. The focus is on understanding how modern LLM systems work internally rather than relying on prompt-only AI responses.
